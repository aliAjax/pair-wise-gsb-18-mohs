# hxwl-04 牙体牙髓知情同意核对台

按患者和牙位管理根管治疗知情同意，替代笼统签字。

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5104

## 功能

- 按「患者 × 牙位」建立核对档案，记录版本号、签署日期、签署人/代办人与四项风险确认
- 计划变化（换牙位开髓、加做显微治疗等）后归档旧版并新建草稿版，须重新确认四项风险并签署
- 未确认签署前，开髓 / 充填登记按钮锁定并提示原因；处置记录注明依据的同意书版本
- 治疗完成后锁定内容；撤销、补签、更正均新建版本，保留原因与旧值快照
- 状态与版本记录存入 localStorage，重开页面不丢失

## 目录结构（资料、判断、存储分离）

- `src/data/` — 资料：风险项、治疗项目、牙位等常量与示例数据
- `src/domain/` — 判断：类型与纯函数业务规则（签署门控、版本流转、处置门控）
- `src/storage/` — 存储：localStorage 读写与回退
- `src/App.tsx` — 界面组装
